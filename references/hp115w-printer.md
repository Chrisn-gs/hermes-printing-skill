# HP115W 打印机参考

## 基本信息

- 型号：HP LaserJet 115w（黑白激光）
- CUPS 队列名：`HP115W`
- 连接方式：网络（IPP）
- 自动双面：不支持
- 耗材：不是白来的，能省则省

## 查看状态

```bash
lpstat -p HP115W          # 打印机状态
lpstat -o HP115W          # 队列中的任务
```

## 卡纸恢复流程

1. 用户手动取出卡纸
2. `cancel HP115W-<id>` 取消当前任务
3. 重新 `lp -d HP115W /tmp/print-output.pdf`
4. **绝对不要跳过取消步骤**，否则旧任务继续出纸导致重复打印

## 打印参数（经用户验证）

省纸模式 65KB 中文文稿约 8 页，标准模式约 10 页。

## 双面打印（手动）

HP115W 不支持自动双面。手动流程：
1. 先打奇数页
2. 翻面放回纸盒
3. 再打偶数页
